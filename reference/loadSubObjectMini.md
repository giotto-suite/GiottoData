# Load a mini giotto subobject

Utility function to load a mini giotto suite S4 subobject. Can be useful
for testing functions quickly or providing contained examples.

## Usage

``` r
loadSubObjectMini(x, idx = 1L)
```

## Arguments

- x:

  subobject type to load

- idx:

  which of multiple example subobjects to load when more than one is
  available (see
  [`listSubObjectMini`](https://giotto-suite.github.io/GiottoData/reference/listSubObjectMini.md))
