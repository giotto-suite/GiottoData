# List available mini giotto subobjects

Lists the available mini giotto subobjects to load. Items are first
classified by the type of subobject, then by the index number which is
used to tell apart files when there is more than one example subobject
of that type available. The final column is the file name.

## Usage

``` r
listSubObjectMini(x = NULL)
```

## Arguments

- x:

  subobject type (NULL lists all subobject types)
